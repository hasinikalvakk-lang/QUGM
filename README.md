## Overview

QUGM (AI-Based Non-Invasive Glucose Monitoring System) is an AI and Machine Learning-based healthcare solution that predicts blood glucose levels without the need for finger-pricking. The system utilizes physiological parameters such as Photoplethysmography (PPG), Blood Pressure (BP), and demographic data to estimate glucose levels and provide early health insights.

The project aims to make glucose monitoring more accessible, comfortable, and user-friendly through non-invasive techniques.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/hasinikalvakk-lang/QUGM.git
```

### 2. Navigate to the Project Directory

```bash
cd QUGM
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

```text
http://localhost:5000
```

## How It Works

1. User enters physiological parameters.
2. Data is preprocessed and validated.
3. The trained XGBoost model analyzes the input.
4. Predicted glucose level is generated.
5. Results are displayed through the web interface.
