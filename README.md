# QUGM - AI-Based Non-Invasive Glucose Monitoring System

## Overview

QUGM (AI-Based Non-Invasive Glucose Monitoring System) is a machine learning and IoT-based healthcare project that estimates blood glucose levels without finger-pricking. The system uses physiological parameters such as Photoplethysmography (PPG), Blood Pressure (BP), and demographic information to predict glucose levels.

## Features

* Non-invasive glucose level estimation
* Machine Learning-based prediction
* Data preprocessing and feature engineering
* User-friendly web interface
* Real-time glucose monitoring support
* Early health risk alerts

## Technology Stack

* Python
* Flask
* Machine Learning (XGBoost)
* HTML, CSS, JavaScript
* Pandas, NumPy, Scikit-learn

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd QUGM
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```
